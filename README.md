# Batyr Runner 🐎

Казахский 2D-раннер: всадник на коне скачет по степи, перепрыгивает юрты, кусты, баранов и тигров, а под беркутами пригибается.

**Играть:** https://yesetsissenov.github.io/horse_game/

Вся игра — один файл `index.html` без зависимостей. Просто откройте его в браузере.

## Возможности

- Цветной пиксель-арт: конь с всадником в чапане и калпаке, юрты с шаныраком, полосатые тигры, отары баранов, беркуты
- Степь с горами в снежных шапках (параллакс), трава, маки; плавная смена дня и ночи со звёздами и луной
- Прыжок с переменной высотой (держите дольше — выше), пригибание
- Беркуты летают на трёх высотах: перепрыгнуть, пригнуться или проскакать под ними
- Тигры и беркуты появляются с ростом счёта; тигр крадётся навстречу
- Управление с клавиатуры и с тачскрина
- Звуки (WebAudio), кнопка мьюта, рекорд в localStorage, пауза

## Управление

| Действие | Клавиши | Тачскрин |
|---|---|---|
| Прыжок | Space / ↑ / W | тап |
| Пригнуться | ↓ / S | удерживать нижнюю треть экрана |
| Пауза | P | — |
| Звук вкл/выкл | M | кнопка 🔊 |

## Отладка

Хэш-параметры: `#demo` — автостарт, `#demo-night` — ночь, `#demo-ff600` — промотать 600 кадров, `#demo-only-yurt` (`tiger`/`sheep`/`eagle`/`bush`) — спавнить только один тип препятствий.
